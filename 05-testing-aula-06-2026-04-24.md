# Geração de plano de testes:

## 1. Utilizar o seguinte prompt:

```
Com base nas especificações do arquivo doc/03-especs.md, elabore um Plano de Testes focado em TDD First, conforme as diretrizes a seguir. 

Para cada funcionalidade, deve-se definir um teste com prioridade a cenários críticos. Quando necessário pode se fazer uso de mocks para simular dependências. s.

A estratégia de teste deve ser automatizada e capaz de validar alterações evitando regressões. 

Revise o arquivo requirements.txt e inclua eventuais dependências necessárias para a execução dos testes. 

O plano de testes gerado deve ser documentado, de forma técnica e estruturada, em arquivo específico chamado testing.md
```

TDD - Test-Driven Development: metodologia de desenvolvimento de *software* em que os testes unitários são escritos antes da construção do código funcional.



## 2. Análise:

- Tente analisar o plano de testes em busca de melhorias. 

- Atualize o prompt para refletir melhor as necessidades do projeto. 

- Execute o novo prompt para gerar nova versão do plano de testes, solicite melhorias pontuais, ou faça as modificações pontualmente. 

## 3. Versionamento:

- Adicione os novos arquivos ao repositório com a opção *add* do GitHub. 

- Consolide a nova versão com a opção *commit* do GitHub

- Faça a sincronização com o repositório remoto. 



#### Observação:

- Repita os passos 1, 2 e 3 até que o plano de testes esteja adequado.
